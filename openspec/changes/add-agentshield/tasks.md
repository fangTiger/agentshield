- [x] 2.1 编写 Agent ID 接口和 `join`：检查 `balanceOf`，每个地址只能登记一次，加入 Semaphore 成员树。验证方式：Foundry 测试覆盖持有者登记、非持有者回滚、重复登记回滚

- [x] 2.4 编写 `statusOf` 状态机，N 和 T 设为 immutable。验证方式：测试待验证、社区确认、冷静期未满、有争议四种状态
